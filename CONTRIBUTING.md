# Contributing

Thanks for helping with Roundtable Report.

## Build

You need Visual Studio 2022 with C++ desktop tools and CMake 3.24+.

```powershell
git clone https://github.com/timlangner/Roundtable-Report.git
cd Roundtable-Report
cmake -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

The public name is Roundtable Report. The DLL, TOML, and `%APPDATA%` folder stay `EldenRing_StatsShare` so existing installs keep working.

## Pull requests

- Tests must pass (`ctest` above).
- Do not commit Discord webhook URLs, DLLs, or files under `docs/superpowers/`.
- Keep sample `webhook_url` empty in `dist/EldenRing_StatsShare.toml`.

## Game patches

If the overlay freezes at 0 after an Elden Ring update, start with:

- `src/game/offsets.cpp` — offset table
- `src/game/aob.cpp` — GameDataMan AOB

NPC / weapon / talisman display names are generated by `tools/gen_name_tables.py` into `src/game/*_name_table.inc`.
