# Security

Roundtable Report is a local Elden Ring overlay. It is not a hosted service.

## Webhooks

Do not put Discord webhook URLs in issues, pull requests, or logs. Keep `webhook_url` empty in sample TOML. If a webhook was ever pasted into a working copy, delete it in Discord and create a new one.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/timlangner/Roundtable-Report/security/advisories/new). Do not file exploit write-ups as public issues.

## Out of scope here

Playing on official online servers with Easy Anti-Cheat is a ban risk. That warning lives in the README.
